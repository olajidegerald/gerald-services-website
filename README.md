# Gerald Services website

This folder contains a responsive, single-page static website. The main file is `index.html`.

## Publish with Netlify

1. Create or sign in to a Netlify account.
2. Choose **Add new site** and the manual deploy option (wording may vary).
3. Drag the `gerald-services-site` folder into the deploy area.
4. Netlify will provide a temporary public URL. Add your custom domain in the site’s domain settings when ready.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder, with `index.html` at the repository root.
2. In repository settings, open **Pages** and choose a deployment source/branch.
3. Save the settings and use the public URL GitHub Pages provides.

## Before sharing with customers

- Replace “Add business email” with a confirmed business email.
- Connect the quote form to a form handler or website platform. The current form is a visual preview and does not send submissions.
- Confirm that the domain is connected to the chosen host.
- Replace the illustrated cargo van with the company’s approved imagery if desired.
